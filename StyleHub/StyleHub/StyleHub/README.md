# StyleHub — Premium Fashion E-Commerce

A responsive frontend-only fashion e-commerce website built with **HTML5, CSS3 and vanilla JavaScript**..

## Features
- Premium fashion landing page
- Men / Women / Kids category browsing
- Product listing with category, size and color filters
- Product search and sorting
- Product detail modal with size selection
- Shopping cart with quantity controls
- Wishlist stored in localStorage
- Coupon code `STYLE20` for 20% off
- Simulated login/register
- Checkout form and simulated order placement
- Newsletter/contact forms
- Responsive mobile navigation
- LocalStorage cart and wishlist persistence
- GitHub Pages compatible

## Files
- `index.html` — complete website structure
- `style.css` — responsive premium styling
- `script.js` — products, filters, cart, wishlist and checkout logic

## Run locally
Open `index.html` in a browser. No backend or database is required.

For VS Code, install the **Live Server** extension and open `index.html` with Live Server.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/root`.
6. Save and wait for GitHub Pages to deploy.
